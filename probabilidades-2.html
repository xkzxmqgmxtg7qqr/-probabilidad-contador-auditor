Introducción a la Probabilidad

La teoría de la probabilidad es la rama de las matemáticas que estudia los fenómenos aleatorios y la incertidumbre. Es fundamental en contabilidad y auditoría para:

  • Evaluar riesgos de auditoría y materialidad
  • Diseñar muestras de auditoría estadísticas
  • Detectar fraudes y errores en estados financieros
  • Tomar decisiones bajo incertidumbre financiera

1. Experimento Aleatorio

Concepto Base

Definición

Un experimento aleatorio es un proceso o acción que puede repetirse bajo las mismas condiciones y cuyo resultado no puede predecirse con certeza antes de realizarlo.

Características:

  • Se puede repetir indefinidamente bajo las mismas condiciones
  • Todos los resultados posibles son conocidos de antemano
  • El resultado específico no se puede predecir con certeza
  • A largo plazo, muestra patrones estadísticos regulares

Ejemplos de Experimentos Aleatorios

📌 Ejemplo 1: Auditoría de facturas

Se selecciona aleatoriamente una factura de un archivo contable para revisión. El resultado puede ser "con errores" (E) o "sin errores" (S). No podemos predecir con certeza el estado de una factura específica antes de revisarla.

📌 Ejemplo 2: Selección de transacciones para muestreo

Un auditor selecciona aleatoriamente una transacción del libro mayor. La transacción puede pertenecer a cualquiera de las cuentas contables (activos, pasivos, ingresos, gastos, patrimonio), pero no sabemos cuál hasta realizar la selección.

📌 Ejemplo 3: Estado de cuentas por cobrar

Se revisa aleatoriamente una cuenta por cobrar del portafolio de clientes. El resultado puede ser "al día", "vencida" o "incobrable". Aunque conocemos las políticas de crédito, no podemos predecir el estado específico de cada cuenta individual.

📌 Ejemplo 4: Tiempo de procesamiento de una declaración de impuestos

Se mide el tiempo que toma procesar una declaración de impuestos. Aunque conocemos el procedimiento estándar, el tiempo exacto varía según la complejidad del caso, disponibilidad de documentación, y otros factores aleatorios.

2. Espacio Muestral

Concepto Base

Definición

El espacio muestral \(\Omega\) (omega) es el conjunto de todos los resultados posibles de un experimento aleatorio.

Notación: \(\Omega = \{e_1, e_2, e_3, \ldots\}\)

Tipos de espacios muestrales:

  • Finito: Contiene un número finito de elementos (ej: lanzar un dado)
  • Infinito numerable: Elementos que pueden contarse (ej: número de llamadas a un centro de atención)
  • Infinito no numerable: No se pueden contar (ej: tiempo de espera, temperatura)

Ejemplos de Espacios Muestrales

📌 Ejemplo 1: Auditoría de una factura

\[\Omega = \{E, S\}\]

Donde E = con Errores, S = Sin errores

📌 Ejemplo 2: Clasificación de una transacción por tipo de cuenta

\[\Omega = \{\text{Activo, Pasivo, Patrimonio, Ingreso, Gasto}\}\]

📌 Ejemplo 3: Revisión de dos facturas consecutivas

\[\Omega = \{EE, ES, SE, SS\}\]

Donde E = con Error, S = Sin error en cada factura

📌 Ejemplo 4: Monto de una cuenta por cobrar vencida (miles de pesos)

\[\Omega = [0, \infty) = \{m : m \geq 0\}\]

Espacio muestral infinito no numerable

📌 Ejemplo 5: Número de errores detectados en un conjunto de asientos contables

\[\Omega = \{0, 1, 2, 3, \ldots\} = \mathbb{N}_0\]

Espacio muestral infinito numerable

3. Suceso o Evento

Concepto Base

Definición

Un suceso o evento \(A\) es cualquier subconjunto del espacio muestral \(\Omega\). Es decir, \(A \subseteq \Omega\).

Tipos de sucesos:

  • Suceso elemental: Contiene un único resultado. Ejemplo: obtener un 5 al lanzar un dado \(A = \{5\}\)
  • Suceso compuesto: Contiene dos o más resultados. Ejemplo: obtener un número par \(A = \{2, 4, 6\}\)
  • Suceso seguro: Es el espacio muestral completo \(\Omega\) (siempre ocurre)
  • Suceso imposible: Es el conjunto vacío \(\emptyset\) (nunca ocurre)

Ejemplos de Sucesos

📌 Ejemplo 1: Tipo de cuenta en el balance

Espacio muestral: \(\Omega = \{\text{Act, Pas, Pat, Ing, Gas}\}\)

(Activo, Pasivo, Patrimonio, Ingreso, Gasto)

  • • Suceso "cuenta del balance": \(A = \{\text{Act, Pas, Pat}\}\)
  • • Suceso "cuenta de resultado": \(B = \{\text{Ing, Gas}\}\)
  • • Suceso "es un activo": \(C = \{\text{Act}\}\) (elemental)
  • • Suceso "es algún tipo de cuenta": \(\Omega\) (seguro)
  • • Suceso "no es ninguno de estos": \(\emptyset\) (imposible)

📌 Ejemplo 2: Auditoría de 3 facturas

Se inspeccionan 3 facturas. \(\Omega = \{EEE, EES, ESE, SEE, ESS, SES, SSE, SSS\}\)

(E = con Error, S = Sin error)

  • • Suceso "todas las facturas tienen errores": \(A = \{EEE\}\)
  • • Suceso "exactamente una factura tiene error": \(B = \{ESS, SES, SSE\}\)
  • • Suceso "al menos una factura tiene error": \(C = \Omega \setminus \{SSS\}\)

📌 Ejemplo 3: Monto de una transacción sospechosa

Monto de transacción: \(\Omega = [0, 10{.}000]\) millones de pesos

  • • Suceso "monto requiere autorización especial": \(A = [500, 10{.}000]\)
  • • Suceso "monto es de alto riesgo": \(B = [2{.}000, 10{.}000]\)
  • • Suceso "transacción es menor": \(C = [0, 100)\)

4. Álgebra de Sucesos

Operaciones

Definición

El álgebra de sucesos es el conjunto de operaciones que se pueden realizar con sucesos: unión, intersección, complemento y diferencia.

1. Unión de sucesos \(A \cup B\)

Ocurre cuando ocurre A, o B, o ambos.

\[A \cup B = \{x : x \in A \text{ o } x \in B\}\]

2. Intersección de sucesos \(A \cap B\)

Ocurre cuando ocurren A y B simultáneamente.

\[A \cap B = \{x : x \in A \text{ y } x \in B\}\]

3. Complemento de un suceso \(A^c\) o \(\bar{A}\)

Ocurre cuando NO ocurre A.

\[A^c = \{x \in \Omega : x \notin A\}\]

4. Diferencia de sucesos \(A \setminus B\) o \(A - B\)

Ocurre A pero NO ocurre B.

\[A \setminus B = \{x : x \in A \text{ y } x \notin B\} = A \cap B^c\]

5. Sucesos mutuamente excluyentes (disjuntos)

No pueden ocurrir simultáneamente.

\[A \cap B = \emptyset\]

Ejemplos de Álgebra de Sucesos

📌 Ejemplo: Clasificación de cuentas

Definamos los sucesos:

  • • \(A\) = "cuenta del balance" = \(\{\text{Act, Pas, Pat}\}\)
  • • \(B\) = "cuenta patrimonial o de ingreso" = \(\{\text{Pat, Ing}\}\)
  • • \(\Omega = \{\text{Act, Pas, Pat, Ing, Gas}\}\)

Unión:

\(A \cup B = \{\text{Act, Pas, Pat, Ing}\}\)

"Cuenta del balance O cuenta patrimonial/ingreso"

Intersección:

\(A \cap B = \{\text{Pat}\}\)

"Cuenta del balance Y patrimonial/ingreso"

Complemento:

\(A^c = \{\text{Ing, Gas}\}\)

"NO es cuenta del balance" (cuentas de resultado)

Diferencia:

\(A \setminus B = \{\text{Act, Pas}\}\)

"Cuenta del balance que NO es patrimonial ni ingreso"

📌 Ejemplo: Auditoría de estados financieros

En una auditoría de estados financieros:

  • • \(A\) = "existen errores materiales en activos"
  • • \(B\) = "existen errores materiales en pasivos"

\(A \cup B\):

Existen errores materiales en al menos una de las dos secciones

\(A \cap B\):

Existen errores materiales en ambas secciones simultáneamente

\(A^c \cap B^c\):

NO hay errores materiales en ninguna sección (opinión limpia)

\(A \setminus B\):

Hay errores en activos pero NO en pasivos

5. Definición de Probabilidad

Fundamental

Definición Axiomática (Kolmogorov)

La probabilidad es una función \(P\) que asigna a cada suceso \(A\) un número real \(P(A)\), satisfaciendo los siguientes axiomas:

Axioma 1 (No negatividad):

\[P(A) \geq 0 \quad \forall A \subseteq \Omega\]

Axioma 2 (Normalización):

\[P(\Omega) = 1\]

Axioma 3 (Aditividad):

Si \(A_1, A_2, \ldots\) son sucesos mutuamente excluyentes:

\[P(A_1 \cup A_2 \cup \cdots) = P(A_1) + P(A_2) + \cdots\]

Interpretaciones de la probabilidad:

  • Clásica (Laplace): Si todos los resultados son igualmente probables:
    \[P(A) = \frac{\text{casos favorables}}{\text{casos posibles}}\]
  • Frecuentista: Basada en la frecuencia relativa a largo plazo:
    \[P(A) = \lim_{n\to\infty} \frac{\text{número de veces que ocurre A}}{n}\]
  • Subjetiva: Grado de creencia personal sobre la ocurrencia de un suceso

Ejemplos de Cálculo de Probabilidades

📌 Ejemplo 1: Clasificación de una transacción

Calcular \(P(A)\) donde \(A\) = "la transacción es una cuenta de balance"

\(\Omega = \{\text{Act, Pas, Pat, Ing, Gas}\}\), todos igualmente probables

\(A = \{\text{Act, Pas, Pat}\}\)

Usando la definición clásica:

\[P(A) = \frac{3}{5} = 0{,}6 = 60\%\]

📌 Ejemplo 2: Muestreo de facturas

De un archivo de 200 facturas, 15 tienen errores de cálculo. Si se selecciona una factura al azar, ¿cuál es la probabilidad de que tenga errores?

Hay 15 facturas con errores de un total de 200

\[P(\text{error}) = \frac{15}{200} = 0{,}075 = 7{,}5\%\]

📌 Ejemplo 3: Morosidad en cuentas por cobrar

En una cartera de 500 clientes, 40 están en mora. Si se selecciona un cliente al azar, ¿cuál es la probabilidad de morosidad?

\[P(\text{moroso}) = \frac{40}{500} = 0{,}08 = 8\%\]
\[P(\text{al día}) = \frac{460}{500} = 0{,}92 = 92\%\]

📌 Ejemplo 4: Auditoría de dos facturas

\(\Omega = \{EE, ES, SE, SS\}\), cada resultado tiene probabilidad 1/4

(E = con Error, S = Sin error)

Sea \(A\) = "exactamente una factura tiene error"

\(A = \{ES, SE\}\)

\[P(A) = P(\{ES\}) + P(\{SE\}) = \frac{1}{4} + \frac{1}{4} = \frac{1}{2} = 50\%\]

6. Propiedades de las Probabilidades

Teoremas

Propiedad 1: Probabilidad del suceso imposible

\[P(\emptyset) = 0\]

Propiedad 2: Probabilidad del complemento

\[P(A^c) = 1 - P(A)\]

Propiedad 3: Acotación

\[0 \leq P(A) \leq 1 \quad \forall A\]

Propiedad 4: Monotonía

Si \(A \subseteq B\), entonces:

\[P(A) \leq P(B)\]

Propiedad 5: Regla de la adición (casos generales)

Para dos sucesos cualesquiera \(A\) y \(B\):

\[P(A \cup B) = P(A) + P(B) - P(A \cap B)\]

Si \(A\) y \(B\) son mutuamente excluyentes, \(P(A \cap B) = 0\)

Propiedad 6: Diferencia de sucesos

\[P(A \setminus B) = P(A) - P(A \cap B)\]

Propiedad 7: Regla de la adición para tres sucesos

\begin{align} P(A \cup B \cup C) = &P(A) + P(B) + P(C) \\ &- P(A \cap B) - P(A \cap C) - P(B \cap C) \\ &+ P(A \cap B \cap C) \end{align}

Ejemplos de Aplicación de Propiedades

📌 Ejemplo 1: Probabilidad del complemento

Si la probabilidad de que una auditoría detecte errores materiales es 0,35, ¿cuál es la probabilidad de NO detectar errores materiales?

Sea \(A\) = "detectar errores materiales", entonces \(P(A) = 0{,}35\)

\[P(A^c) = 1 - P(A) = 1 - 0{,}35 = 0{,}65 = 65\%\]

📌 Ejemplo 2: Regla de la adición

En una empresa:

  • • 45% de las transacciones son de compras (\(P(C) = 0{,}45\))
  • • 35% son de ventas (\(P(V) = 0{,}35\))
  • • 10% son devoluciones que afectan ambas cuentas (\(P(C \cap V) = 0{,}10\))

¿Cuál es la probabilidad de que una transacción elegida al azar sea de compras O ventas?

\begin{align} P(C \cup V) &= P(C) + P(V) - P(C \cap V) \\ &= 0{,}45 + 0{,}35 - 0{,}10 \\ &= 0{,}70 = 70\% \end{align}

📌 Ejemplo 3: Sucesos mutuamente excluyentes

Una factura se clasifica en una de las siguientes categorías. Sea \(A\) = "factura pagada" y \(B\) = "factura vencida"

\(P(A) = 0{,}75\), \(P(B) = 0{,}18\)

Como \(A \cap B = \emptyset\) (una factura no puede estar pagada y vencida simultáneamente):

\[P(A \cup B) = P(A) + P(B) = 0{,}75 + 0{,}18 = 0{,}93 = 93\%\]

El 7% restante corresponde a facturas en proceso

📌 Ejemplo 4: Monotonía

Clasificación de estados financieros:

  • • \(A\) = "existen errores materiales en activos corrientes"
  • • \(B\) = "existen errores materiales en activos (corrientes o no corrientes)"

Supongamos \(P(A) = 0{,}12\) y \(P(B) = 0{,}20\)

Como \(A \subseteq B\) (los activos corrientes son un subconjunto de los activos):

\[P(A) = 0{,}12 \leq 0{,}20 = P(B)\]

✓ Se cumple la propiedad de monotonía

7. Teorema de Bayes

Avanzado

Conceptos previos necesarios:

1. Probabilidad condicional

La probabilidad de \(A\) dado que ocurrió \(B\):

\[P(A|B) = \frac{P(A \cap B)}{P(B)}, \quad P(B) > 0\]

2. Regla del producto

\[P(A \cap B) = P(A|B) \cdot P(B) = P(B|A) \cdot P(A)\]

3. Teorema de la probabilidad total

Si \(B_1, B_2, \ldots, B_n\) forman una partición de \(\Omega\):

\[P(A) = \sum_{i=1}^{n} P(A|B_i) \cdot P(B_i)\]

Teorema de Bayes

Permite calcular probabilidades "inversas" o "a posteriori". Si \(B_1, B_2, \ldots, B_n\) forman una partición del espacio muestral:

\[P(B_i|A) = \frac{P(A|B_i) \cdot P(B_i)}{\sum_{j=1}^{n} P(A|B_j) \cdot P(B_j)}\]

Donde:

  • • \(P(B_i)\) = probabilidad a priori de \(B_i\)
  • • \(P(A|B_i)\) = verosimilitud (likelihood)
  • • \(P(B_i|A)\) = probabilidad a posteriori de \(B_i\)

Ejemplos del Teorema de Bayes

📌 Ejemplo 1: Detección de fraude contable

Un sistema de detección de fraude en estados financieros tiene las siguientes características:

  • • El 2% de los estados financieros auditados contienen fraude: \(P(F) = 0{,}02\)
  • • Si hay fraude, el sistema lo detecta en el 90% de los casos: \(P(D|F) = 0{,}90\)
  • • Si NO hay fraude, el sistema da alerta falsa en el 8% de los casos: \(P(D|F^c) = 0{,}08\)

Pregunta: Si el sistema detecta una alerta, ¿cuál es la probabilidad de que realmente exista fraude?

Solución:

Queremos calcular \(P(F|D)\). Datos:

  • • \(P(F) = 0{,}02\), por tanto \(P(F^c) = 0{,}98\)
  • • \(P(D|F) = 0{,}90\)
  • • \(P(D|F^c) = 0{,}08\)

Aplicando el Teorema de Bayes:

\begin{align} P(F|D) &= \frac{P(D|F) \cdot P(F)}{P(D|F) \cdot P(F) + P(D|F^c) \cdot P(F^c)} \\[10pt] &= \frac{0{,}90 \times 0{,}02}{0{,}90 \times 0{,}02 + 0{,}08 \times 0{,}98} \\[10pt] &= \frac{0{,}018}{0{,}018 + 0{,}0784} \\[10pt] &= \frac{0{,}018}{0{,}0964} \approx 0{,}187 \approx 18{,}7\% \end{align}

Interpretación:

Aunque el sistema dio alerta, la probabilidad de fraude real es solo del 18,7%. El auditor debe profundizar con procedimientos adicionales. La baja prevalencia de fraude (2%) y la tasa de falsas alarmas (8%) explican este resultado.

📌 Ejemplo 2: Origen de errores contables

Una empresa tiene tres departamentos que procesan transacciones contables:

  • • Departamento A procesa el 40% de las transacciones y tiene 3% de error
  • • Departamento B procesa el 35% de las transacciones y tiene 5% de error
  • • Departamento C procesa el 25% de las transacciones y tiene 2% de error

Pregunta: Si se encuentra una transacción con error, ¿cuál es la probabilidad de que provenga del departamento B?

Solución:

Definamos:

  • • \(A, B, C\) = transacción proviene del departamento A, B o C
  • • \(E\) = transacción tiene error

Datos:

  • • \(P(A) = 0{,}40\), \(P(B) = 0{,}35\), \(P(C) = 0{,}25\)
  • • \(P(E|A) = 0{,}03\), \(P(E|B) = 0{,}05\), \(P(E|C) = 0{,}02\)

Aplicando el Teorema de Bayes:

\begin{align} P(B|E) &= \frac{P(E|B) \cdot P(B)}{P(E|A) \cdot P(A) + P(E|B) \cdot P(B) + P(E|C) \cdot P(C)} \\[10pt] &= \frac{0{,}05 \times 0{,}35}{0{,}03 \times 0{,}40 + 0{,}05 \times 0{,}35 + 0{,}02 \times 0{,}25} \\[10pt] &= \frac{0{,}0175}{0{,}012 + 0{,}0175 + 0{,}005} \\[10pt] &= \frac{0{,}0175}{0{,}0345} \approx 0{,}507 \approx 50{,}7\% \end{align}

Interpretación:

Hay aproximadamente 50,7% de probabilidad de que el error provenga del departamento B. Aunque procesa menos transacciones que A, tiene la mayor tasa de errores, por lo que es el departamento más probable como origen del error detectado.

📌 Ejemplo 3: Control interno y detección de irregularidades

Un sistema de control interno tiene las siguientes características:

  • • La probabilidad de una irregularidad material es 0,5% por mes: \(P(I) = 0{,}005\)
  • • Si hay irregularidad, el control la detecta en el 95% de los casos: \(P(C|I) = 0{,}95\)
  • • Si NO hay irregularidad, el control genera alerta falsa en el 4% de los casos: \(P(C|I^c) = 0{,}04\)

Pregunta: Si el sistema de control genera una alerta, ¿cuál es la probabilidad de que realmente exista una irregularidad?

Solución:

\begin{align} P(I|C) &= \frac{P(C|I) \cdot P(I)}{P(C|I) \cdot P(I) + P(C|I^c) \cdot P(I^c)} \\[10pt] &= \frac{0{,}95 \times 0{,}005}{0{,}95 \times 0{,}005 + 0{,}04 \times 0{,}995} \\[10pt] &= \frac{0{,}00475}{0{,}00475 + 0{,}0398} \\[10pt] &= \frac{0{,}00475}{0{,}04455} \approx 0{,}107 \approx 10{,}7\% \end{align}

Interpretación profesional:

Aunque el sistema de control generó una alerta, hay solo 10,7% de probabilidad de irregularidad real. El auditor debe:

  • • Realizar procedimientos analíticos adicionales
  • • Revisar documentación de respaldo
  • • Evaluar el contexto y patrones históricos
  • • No concluir irregularidad solo por la alerta

La baja prevalencia base (0,5%) y las falsas alarmas explican que la mayoría de alertas no correspondan a irregularidades reales.
